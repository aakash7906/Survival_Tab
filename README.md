# SurvivalTabs

A modern React application built with TypeScript, Vite, Tailwind CSS, Shadcn UI, Lucide React icons, and React Router.

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI patterns
- **Icons:** Lucide React
- **Routing:** React Router v7

## Getting Started

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Preview
```bash
npm run preview
```
